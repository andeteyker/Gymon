# Progression Simulation

The simulation harness stress-tests Gymon's reward economy before beta telemetry exists.

It compares representative strength, hypertrophy, calisthenics, endurance and mixed-training athletes over a configurable number of weeks. All baseline profiles use equal session frequency, similar adherence, equal trust and the same personal-improvement assumption so differences primarily expose reward-model bias.

## What to watch

- Average XP per week should remain in the same broad progression band for legitimate training styles.
- Hypertrophy must not win simply because it contains more exercises.
- Strength must not win because of absolute load.
- Endurance must not lose simply because a session contains fewer exercise records.
- Calisthenics must remain viable without external load.
- Mixed training should not gain an artificial advantage by touching more categories.

## Next calibration step

Run this harness whenever XP constants, exercise base-effort values or session caps change. Once beta telemetry exists, replace representative assumptions with anonymized distributions of session duration, adherence, exercise count and personal progression. Balance around productive behavior rather than making every workout produce exactly identical XP.
